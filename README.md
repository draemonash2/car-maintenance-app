# カーメンテナンス

車のメンテナンス時期を管理する、iPhone向けの無料Webアプリ（PWA）です。
オイル交換やタイヤ交換などの時期を、前回からの期間と走行距離で計算し、近づいたらバッジと通知で知らせます。

**アプリのURL:** https://draemonash2.github.io/car-maintenance-app/

## 主な機能

- **複数の車を管理**：車ごとにアイコンと色を選べます。
- **メンテナンス項目のテンプレート**：エンジン種別（ガソリン / ハイブリッド / ディーゼル / EV / その他）とミッション種別（AT / CVT / MT / その他）に合わせて、よく使う項目と交換目安をまとめて登録できます。登録後に車へテンプレートを追加することもできます。各項目に説明が付いています。
- **時期の判定**：前回の実施日・走行距離と交換目安（○か月・○km）から、「超過」「まもなく」「OK」を表示します。
- **メンテナンス履歴**：実施日・走行距離・メモを記録し、あとから編集・削除できます。
- **メンテナンス予定**：「次のオイル交換のときに一緒に替える」など、すぐ対応しない項目は日付や走行距離を予定として設定できます。その時期が来るまで、バッジと通知の対象から外れます。
- **走行距離の推移**：総走行距離の記録を折れ線グラフで表示し、年間・月間の平均走行距離を計算します。遠出の内容などをメモできます。
- **バッジと通知**：対応が必要な項目の数をアプリのアイコンにバッジで表示します。通知は、時期が来た項目ごとに1回だけ届きます。
- **バックアップと復元**：データをファイル（JSON）に書き出し、あとで読み込めます。最後のバックアップから30日たつと、画面上部でお知らせします。
- **オフライン対応**：一度開けば、電波がない場所でも使えます。
- **ダークモード対応**：iPhoneの設定に合わせて表示が切り替わります。

## 使い方

### iPhoneのホーム画面に追加する

1. iPhoneの **Safari** で上記のURLを開きます。
2. 画面下の共有ボタン（四角から上向き矢印のアイコン）をタップします。
3. **「ホーム画面に追加」** を選び、「追加」をタップします。
4. ホーム画面にできた「カーメンテナンス」のアイコンから起動します。

バッジと通知を使うには、ホーム画面から起動したうえで、通知を許可してください（iOS 16.4以降）。

### 基本の流れ

1. 右上の **＋** で車を登録します（名前・購入日・総走行距離・エンジン種別・ミッション種別・アイコン）。
2. テンプレートを使うと、メンテナンス項目がまとめて登録されます。項目はあとから追加・編集・削除できます。
3. メンテナンスをしたら、項目を開いて **メンテナンスを記録する** をタップします。次回の時期が自動で計算されます。
4. ときどき **走行距離を記録** で総走行距離を更新すると、距離による判定とグラフが正確になります。

### バックアップ

右上のアーカイブアイコンから「データ管理」を開き、**バックアップを保存** でファイルを保存します。
iPhoneでは共有画面が開くので、「ファイルに保存」やiCloud Driveなどに保存してください。
復元するときは、同じ画面の **バックアップから復元** でファイルを選びます。

## 注意事項

- **データはiPhoneの中にだけ保存されます。** サーバーには送信しません。
- **ホーム画面からアプリを削除すると、データも消えます。** 機種変更のときも引き継がれません。削除や機種変更の前に、必ずバックアップを書き出してください。
- **時期のチェックは、アプリを開いたときに行います。** アプリを開いていない間は、バッジや通知は更新されません。
- iPhoneのホーム画面ウィジェットには対応していません（Webアプリの制限です）。
- Androidでも、Chromeで開いて「ホーム画面に追加」すれば使えます。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | アプリ本体（画面・処理をすべて含む） |
| `sw.js` | Service Worker（オフライン用のキャッシュと通知） |
| `manifest.json` | ホーム画面に追加するときのアプリ名・アイコンなどの設定 |
| `apple-touch-icon.png` | iPhoneのホーム画面用アイコン（180×180） |
| `icon-192.png` / `icon-512.png` | アプリアイコン（通知・Android用） |

外部のライブラリやサーバーは使っていません。データはブラウザの localStorage に保存しています。

## 開発者向けメモ

### 手元で動かす

このフォルダで簡単なWebサーバーを起動し、ブラウザで開きます。

```bash
python -m http.server 8000
```

ブラウザで http://localhost:8000/ を開きます。

### 更新を公開する

`main` ブランチにプッシュすると、GitHub Pages に反映されます。

`index.html` などを変更したら、`sw.js` の `CACHE` の番号（例：`car-maint-v19` → `car-maint-v20`）を1つ上げてください。
上げないと、インストール済みのアプリで古いファイルが使われ続けることがあります。
